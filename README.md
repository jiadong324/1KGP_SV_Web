# 1KGP SV Resource & Guidance

Community guidance for per-genome SV discovery, population integration, genotyping, rare SV filtering and biobank PheWAS.

Static website: index.html, app.js and style.css. No build step is needed.

## GitHub Pages

In Settings → Pages, select Deploy from a branch, main, and / (root). The expected address after publication is https://jiadong324.github.io/1KGP_SV_Web/.

## Local preview

Run `python3 -m http.server 8765` and open http://localhost:8765.
